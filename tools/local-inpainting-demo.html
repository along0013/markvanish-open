Local inpainting demo

Select an image, paint over the region you want removed, then press Fill. Everything runs in this page with the Canvas API. Nothing is uploaded.

24 px

How it works: the painted pixels are marked unknown, then each pass replaces an unknown pixel with the average of the neighbours that are known at that moment. Pixels are visited in row order and marked known immediately, so a single pass already sweeps across most of a region — the pass count in the status line shows when that happens. This is a single-scale diffusion fill: it works well on short text, small marks, and simple textures, and it will smear on large regions or strong gradients.

HEIC/HEIF will not open in browsers that cannot decode it locally. That limitation is intentional: adding server-side conversion would break the "no upload" property.
